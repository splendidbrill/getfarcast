# Plan: Migrate Playbooks to AWS RDS PostgreSQL

## Goal
Set up AWS RDS PostgreSQL database and modify the codebase to save generated playbooks to RDS instead of localStorage.

## Assumptions
- User has AWS account with appropriate permissions (confirmed)
- Using PostgreSQL latest version for structured JSON storage
- Playbooks stored as JSONB in a table
- Using Prisma ORM for database management
- Standard security: VPC, IAM, no public access except for development

## AWS RDS Setup Steps

### 1. Create RDS Instance
- Go to AWS Console → RDS
- Choose "Create database"
- Select PostgreSQL (latest version)
- Choose instance class (e.g., db.t3.micro for free tier if eligible)
- Set database name (e.g., getfarcast)
- Configure security group in VPC to allow connections from your app's IP (use 0.0.0.0/0 only for development)
- Note down endpoint, port (5432), username, password

### 2. Configure Database
- Connect to RDS using psql or pgAdmin
- Create table: `playbooks`
  ```sql
  CREATE TABLE playbooks (
    id VARCHAR(255) PRIMARY KEY,
    user_id VARCHAR(255),
    product_name TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    data JSONB
  );
  ```
- Create index on user_id for faster queries

### 3. Update Environment Variables
- Add RDS connection details to .env.local:
  ```
  DATABASE_URL=postgresql://username:password@endpoint:5432/database_name
  ```

## Code Changes

### 1. Install Prisma
- Add `prisma` and `@prisma/client` to package.json
- Initialize Prisma with `npx prisma init`

### 2. Define Schema
- Update `prisma/schema.prisma` with Playbook model

### 3. Create Database Connection Module
- Create `src/lib/db.ts` with Prisma client

### 3. Modify generate-playbook/route.ts
- Replace localStorage save with database insert
- Use parameterized queries to prevent SQL injection

### 4. Update Dashboard Page
- Change to server component fetching from database
- Add authentication checks

### 5. Update Playbook Page
- Load from database instead of localStorage

### 6. Modify Feedback Actions
- Change updatePostFeedback to update database

### 7. Migration Script
- Create `scripts/migrate-localstorage.js` to read localStorage and insert into RDS
- Run after deployment: `node scripts/migrate-localstorage.js`
